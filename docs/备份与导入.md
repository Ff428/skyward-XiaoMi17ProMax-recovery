## 三、备份是怎么做的

两步脚本，都在 `D:\WorkBuddyAI\tmp\`。

### 第一步：`bk7_step1.py`（搬文件）

1. `output/` 只留两个产物：把不是这两个 img 的文件与 `archive/` 挪到
   `D:\WorkBuddyAI\tmp\output-before-cleanup-20261126-v07\`（可逆），再拷入两个新 img，
   写两行 `SHA256SUMS`。
2. `copytree` 整个仓库到 `repo/`，忽略 `out/`、`target/`、`stock/base.img`。
3. 校验 `repo/stock/recovery.img` 的 sha 与 `devices/popsicle.toml` 里的 `[stock] recovery`。
4. `git bundle create repo.bundle --all`，`git bundle verify`，把 `list-heads` 写进 `env/`。
5. 拷两个 img 到 `artifact/`，写两行 `SHA256SUMS`。
6. 拷 `docs/*.md` 与根目录的 `README/AGENTS/LICENSE/Cargo.*/rust-toolchain.toml`。
7. 拷 `.workbuddy/`、`scripts/`、`tmp/*.py|sh|json`（小于 2 MB）。
8. 写 `env/版本与提交.txt`、`paths.json`，拷 `.cargo/config.toml` 与 `build.yml`。

### 第二步：`bk7_step2.py`（清单、校验和、打包）

1. 把 `C:/Users/F/.cargo/registry` 的 `cache/` 与 `index/` 拷进 `offline/cargo-registry/`
   （`src/` 不收：cargo 会从 `.crate` 自动展开）。
2. 根目录 `.ps1` 加 UTF-8 BOM（PowerShell 5.1 才不把中文当 GBK），`.sh` 统一 LF。
3. 遍历整棵目录，跳过 `MANIFEST.json`、`SHA256SUMS`、`repo/.git/index`、`*.lock`，
   逐文件算 sha256，写 `MANIFEST.json`。
4. 写 `SHA256SUMS`（2140 个文件 + `MANIFEST.json`，共 2141 行）。
5. 打包：固定 `date_time=(2026,11,26,12,0,0)`，`.sh` 写 0755、其余 0644，deflate level 6。
6. 算 zip 的 sha256 写 sidecar。
7. 验证：CRC、条目数、14 个关键文件（含两个 img）。
8. 备份内仓库跑一次 `git status --short` 与 `git log --oneline`。

重跑命令：

```powershell
cd D:\WorkBuddyAI\tmp
python bk7_step1.py
python bk7_step2.py
```

两个脚本都可重复运行：第一步会清掉同名备份目录重建；`output/` 里已回收过的重复项
直接丢掉、不再二次移动。

## 五、在另一台电脑导入

默认还原到原机两个绝对路径：工作区 `D:\WorkBuddyAI\2026-11-13-20-45-53`、
仓库 `D:\WorkBuddyAI\skyward-XiaoMi17ProMax-recovery`。**路径一致才能逐字节复现**
（Rust 把源码绝对路径嵌进二进制）；换路径照样能构建、功能一致，字节不同。

Windows：

```powershell
cd <解压后的目录>
powershell -ExecutionPolicy Bypass -File .\导入.ps1
# 换位置：
powershell -ExecutionPolicy Bypass -File .\导入.ps1 -Workspace D:\Work\skyward-task -Repo D:\Work\skyward-XiaoMi17ProMax-recovery
# 已有 Cargo 缓存、不复制离线依赖：
powershell -ExecutionPolicy Bypass -File .\导入.ps1 -SkipOffline
```

Linux / macOS：

```sh
cd <解压后的目录>
sh ./导入.sh
WORKSPACE="$HOME/skyward-task" REPO="$HOME/skyward-XiaoMi17ProMax-recovery" sh ./导入.sh
```

导入器依次做：

1. 逐文件校验 `SHA256SUMS`（2141 行），有任何不符就停。
2. `git bundle verify`（在 `repo/` 里跑，`git bundle verify` 把 `is okay` 写到 stderr，
   所以用 `cmd /c` 收住、只看退出码）。
3. 还原 `repo/` 到目标仓库路径（robocopy `/E`，只覆盖同名）。
4. 还原工作区：`.workbuddy/`、`scripts/`、`tools/`、`docs/`、`output/`（两个产物）。
5. 按需把 `offline/cargo-registry` 拷到 `%USERPROFILE%\.cargo\registry`
   （目标已存在就跳过，不覆盖）。
6. 工具链自检：`git` / `python` / `cargo` / `dlltool` / `lz4` / `python -c "import lz4.block"` /
   NDK r29 / Rust 1.100.0，缺哪项打印怎么装。

## 六、重新构建

工具链（另一台电脑按这个装）：

| 组件 | 版本 / 位置 | 安装 |
|---|---|---|
| Python | 3.13+，需 `lz4` | `python -m pip install lz4` |
| git | 2.55+ | 任意发行版 |
| Rust | **1.100.0** + `aarch64-linux-android` std | `rustup toolchain install 1.100.0 --target aarch64-linux-android` |
| Android NDK | r29 | 设 `ANDROID_NDK_HOME`，或放 `D:/WorkBuddyAI/downloads/ndk_r29/android-ndk-r29` |
| mingw-w64 | 只要 `dlltool.exe` | 放 PATH，或 `D:/软件/应用/mingw64/mingw64/bin` |
| lz4 命令行 | 任意 | 放 PATH，或 `D:/WorkBuddyAI/downloads/lz4` |

```powershell
powershell -ExecutionPolicy Bypass -File .\重建.ps1
```

```sh
WORKSPACE="$HOME/skyward-task" sh ./重建.sh
```

脚本设 `SKYWARD_OUTPUT_DIR` 与 `CARGO_TARGET_DIR`，先跑 `scripts/local_build.py --deliver`
出品牌版，再 `touch crates/skyward-ui/src/pages.rs` 并带

```text
SKYWARD_BRAND_TITLE=Skyward
SKYWARD_BRAND_AUTHOR=© 2026 Skyward
SKYWARD_BRAND_WORDMARK=Skyward
```

跑 `--official --deliver` 出官方版。品牌常量是编译期 `option_env!`，不 `touch` 不会重编。

八步：交叉编译 recovery、编译静态 system-init、编译打包器、取原厂底包、注入 HAL 层、
打包重算 AVB、四项自检、算摘要。末行应为 `ALL CHECKS PASSED`。

**验证可重建**：从解压出来的备份仓库跑一次，本次实测通过，
产出 sha `a4ddb1bda0b7b7ca6cf31d6de6b65d1d07cce61276123fd0d6e93b09e0d1eb6a`
——与备份里的 `dd6232b4…` 不同，因为构建路径变了。

## 七、踩过的坑

| 坑 | 现象 | 处理 |
|---|---|---|
| `deliver()` 互相挪包 | 出官方版时品牌版被移进 `archive/`，两个留不住 | 两个 `SKYWARD_OUTPUT_DIR` 分开（`tmp/bk-out/brand` 与 `tmp/bk-out/official`） |
| `git bundle create --all` 只含本地 refs | 本地删过 `v1`（远端用 API 重建），bundle 里没有 v1 | `git fetch origin --tags` 后再重建 bundle，并把 `.git` 重新拷进 `repo/` |
| PowerShell 5.1 中文乱码 | `.ps1` 无 BOM 时按 GBK 读 | 第二步给根目录 `.ps1` 加 UTF-8 BOM |
| `git bundle verify` 在 `Stop` 下报错 | 它把 `is okay` 写到 stderr，被当 NativeCommandError | 用 `cmd /c` 收住，只看退出码；且必须在仓库里跑 |
| `.git/index` 每次 git 命令都变 | 纳入校验会永远失败 | 清单与校验都跳过 `repo/.git/index` 与 `*.lock` |
